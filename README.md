# 🚗 Chevrolet Sonic – Apresentação Online

Uma plataforma digital desenvolvida para a divulgação do **novo Chevrolet Sonic**, oferecendo uma experiência visual moderna, responsiva e envolvente para apresentar os principais destaques do veículo.

🌐 **Site Oficial do Projeto:**  
https://chevrolet-sonic.vercel.app

---

## 📖 Sobre o Projeto

O **Chevrolet Sonic** foi desenvolvido como uma landing page de marketing digital voltada para a apresentação do veículo ao público. O objetivo é destacar seu design, desempenho e características de forma atrativa, proporcionando uma navegação intuitiva e uma experiência visual impactante.

---

## 🎯 Objetivos

- Apresentar o novo Chevrolet Sonic de forma moderna e atrativa.
- Destacar os principais diferenciais e características do veículo.
- Criar uma experiência digital responsiva para diferentes dispositivos.
- Servir como vitrine online para campanhas de marketing e divulgação.

---

## ✨ Funcionalidades

✔️ Design moderno e responsivo  
✔️ Interface intuitiva e agradável  
✔️ Apresentação visual dos destaques do veículo  
✔️ Compatibilidade com dispositivos móveis e desktop  
✔️ Navegação fluida e otimizada
